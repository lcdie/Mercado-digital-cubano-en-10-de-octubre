## Consideraciones de privacidad

- Todos los audios deben estar anonimizados antes de incluirse en el repositorio público.
- No se incluyen transcripciones con datos personales identificables.
- Los audios respaldan principalmente los hallazgos de opacidad (D1-D5) e informalidad (E1-E5) del informe final.
- No subir a GitHub si contienen nombres, teléfonos o direcciones sin eliminar primero esa información.

# Entrevistas de audio — Evidencia no técnica

Esta carpeta contiene grabaciones de entrevistas anónimas realizadas para el proyecto de mercado inmobiliario en Diez de Octubre.

## Estructura de nombres

Usa el formato `E-NN.ext` donde `NN` es un número secuencial (ej. `E-01.mp3`, `E-02.mp3`).

No uses nombres reales de personas en los archivos.

## Consideraciones

- Todos los audios deben estar anonimizados antes de incluirse en el repositorio.
- No se incluyen transcripciones con datos personales identificables.
- Los audios respaldan principalmente los hallazgos de opacidad (D1-D5) e informalidad (E1-E5) del informe final.
